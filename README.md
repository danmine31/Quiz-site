# Тематические викторины (Quiz Hub)

Интерактивный веб-каталог викторин по различным областям знаний

## Стек технологий
- HTML5 (семантическая верстка, доступность a11y)
- CSS3 (CSS Custom Properties, Flexbox, CSS Grid)
- Vanilla JavaScript (DOM API, LocalStorage, MatchMedia)

## Реализованный функционал
- [x] Переключение светлой и тёмной темы с сохранением выбора в `localStorage`
- [x] Учёт системных настроек темы пользователя (`prefers-color-scheme`)
